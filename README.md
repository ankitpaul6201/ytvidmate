# ytvidmate
YTVidMate is a free web tool that lets you download videos just by pasting a link. You paste the URL, choose a quality from 360p up to 4K (or audio-only MP3), and get the file with proper sound. It uses yt-dlp to fetch the video and FFmpeg to merge the separate video and audio streams, so you don't end up with silent or low-quality downloads.
